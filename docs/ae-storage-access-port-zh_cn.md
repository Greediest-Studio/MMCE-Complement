# AE 存储访问端口

方块 ID：`mmce_complement:ae_storage_access_port`，显示名为“ME存储访问端口”。

将端口作为方块加入存储器的结构 JSON，然后用 AE 线缆连接端口即可。每个端口占用 1 个频道，需要 AE 网络供电。端口沿用 MMCE 仓室的外壳染色机制。

成型后，机器 JSON 声明的物品、流体存储会直接成为网络中的可读写库存，无需额外放置 ME 存储总线。气体存储接入还需要 Mekanism 与 Mekanism Energistics，气体显示及操作使用对应的气体终端。未声明的存储类型不会提供容量。

端口只访问所在成型存储器，普通机器不会通过端口提供库存。临时拆坏结构后，库存继续封存在控制器中，AE 无法访问；重新成型后恢复。同一存储器连接同一网络的多个端口仅展示一份库存，避免重复计算。

AE 的模拟查询不会改变内容。终端存取、容器 GUI、输入输出仓室使用同一份底层存储，外部修改会同步到网络。端口本身不保存物品、流体或气体。
